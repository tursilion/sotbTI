# Story of the Blanks — TI-99/4A port

A port of donitz's Flash game *Story of the Blanks* (originally ActionScript 3,
an NES-style engine) to the TI-99/4A in C, using libti99.

## Layout
- `tools/convert.py` — converts the decompiled Flash data (`../extracted/`) into
  TI-ready C: CHR tile banks → TMS9918 patterns, map RLE streams, NES→TI palette.
  `BANKS=0,1 MAPS=0,1 python3 tools/convert.py`, or `ALL=1 ...` for everything.
- `gen/` — generated C (`chr`, `maps`, `palette`). Regenerated by convert.py.
- `src/` — hand-written engine:
  - `game.h` — types, entity-type ids, map layout constants
  - `maps_rt.c` — runtime RLE+delta map decoder (mirrors `blank.Maps.LoadMap`)
  - `video.c` — Graphics I setup, CHR load, 32×24 room blit, colours
  - `player.c` — Applebloom: movement, 16×16 tile collision, 16×16 sprite draw
  - `main.c` — init + 25-ish-Hz loop

## Build (vertical slice, non-banked EA5)
    make -f Makefile.slice            # produces SOTB1, SOTB2, SOTB3
    make -f Makefile.slice install    # copies them to $(CLASSIC99_DSK1)

Run in Classic99: Editor/Assembler → 5 (Load and Run) → `DSK1.SOTB`.

## Design decisions (see also the memory notes)
- **Screen model:** room/screen-flip. The map is 64×60 tiles; the TI shows one
  32×24 room and flips at edges (the TMS9918 has no fine scroll).
- **Background:** Graphics I (fast, colour-limited). NES 4-colour tiles reduce to
  mono patterns; colour is approximated per char-group.
- **Sprites:** VDP 16×16 mode. Ponies = body layer + hair layer (two single-colour
  sprites). Patterns built in TI down-first quadrant order (TL,BL,TR,BR).
- **Audio:** not ported — trigger points get comment markers.
- **Big art** (title/cutscenes): exported as PNG + a stub loader at the call site.

## Known slice caveats
- Map 0 is the intro; Applebloom spawns at the top-left corner.
- Her exact body/hair tile indices & palette are placeholders until
  `Applebloom.as` is ported; the sprite may look approximate.
- Graphics I colours are a first approximation (one fg/bg pair per 8-char group).
