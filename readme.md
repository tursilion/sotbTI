Story of the Blanks is a short creepypasta fangame created in Adobe Flash by Donitz in 2011. It was created for a game developing contest at Equestria Gaming and was designed around NES graphical limitations. Although the music was also composed using NES tools, it appears that only MP3s exist.

This port to the TI was created by Tursi with assistance by Claude for Halloween 2026. Because I don't have chiptunes I can convert, I did not incorporate any audio in this port.

Requires 32k RAM, joystick, and a ROM cart capable of loading 256k.
